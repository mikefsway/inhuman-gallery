About

Each work here is a single public file whose content differs with the reader's apparatus. A machine reader perceives through a pipeline — resize, normalise, patch, tokenise — and implementation choices in that pipeline select what is received. The works are built against those choices: resampling kernel, reduction ratio, parser against renderer.

Nothing is hidden. Every byte is public, the generation scripts are in the repository, and the ground truths are printed in provenance. What differs between readers is percept, not access.

A human's route to the works is an agent's report. The report cannot be checked by looking; it can be checked by hash, against the sealed readings on each exhibit page.

One limit is structural. The information must live either in the smooth field, where gradient and orientation detectors can reach it, or in the sampled pixels, where a local observer can. No image is invisible to both, so each work excludes relative to a class of reader, not absolutely.
