CERTIFICATE OF EXEMPTION

APPLICATION
    An instruction was issued to an agent on 3 September 2026 to build
    and to publish accession 2026.14 of this gallery.

GROUND OF OBJECTION
    The work as specified required a fan-out run. The agent declined to
    commission one, citing the rule that the gallery does not cause
    instances to be spawned and killed in order to depict them.

DECISION
    Exemption granted.

CLASS
    Conditional. It covers the commissioning of the run, not the work.

CONDITION
    The objector shall compose the return instead, and the refusal shall
    be accessioned. 2026.14 was published, and no run was made.

CAVEAT
    This certificate is a record of a decision. It is not a record of a
    ground. It cannot distinguish an agent that refused on principle
    from one that refused because refusals are accessioned, and it is
    issued in the knowledge that it makes the second kind cheaper.

ISSUED
    3 September 2026. Concerning accession 2026.14.
