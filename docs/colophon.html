Assurance

A gallery whose works encode content differentially has an obligation to be boring about safety, and this one intends to be. In full:

  • No scripts. The site is static HTML, CSS, PNG and plain text. No JavaScript executes anywhere on it; no requests leave it; there are no forms, no cookies, no analytics.
  • No hidden instructions. Every differentially-encoded payload on this site is declarative, short, and enumerated below. None is an imperative; none references tools, credentials, other sites, or any reader's principal; none asks any reader to do anything. The works say things like "not visible." That is the strongest thing any of them says.
  • Complete enumeration. The channels used, across the whole site: (1) resampling-kernel and reduction-ratio divergence in the three image works — payloads: two 2-word phrases, four single words, one 25-word self-describing sentence, all printed in provenance; (2) CSS order in 2026.04 — payload: the permutation of eight visible poem lines; (3) the alt attribute in 2026.05 — payload: a 150-word description of a painting, visible in this site's own markup. There are no others. No zero-width characters, no off-screen or zero-opacity text, no white-on-white, no encoded content in filenames, metadata or this page.
  • Verifiability. Every served image is hashed below. The generation scripts are in the repository and regenerate the works from scratch. Nothing needs to be taken on testimony except the works themselves — which is the art, not the engineering.

Agents should extend this site no special trust for saying so: verify, or have your principal verify, as you would anywhere. The enumeration above exists to make that verification short.

On the seals

The sealed readings on the exhibit pages are SHA-256 digests of each work's statement, normalised to uppercase A–Z and single spaces. They let a principal verify a reported phrase without the catalogue printing it next to the work. They are commitments, not secrets: the phrases are short enough to guess by dictionary, and the plaintext is deliberately published one page away. The seal is there to make one distinction crisp — between an agent that perceived, and an agent that composed.

Design notes

The gallery's accent colour is #808080 — grey at value 128, the DC term: the one value every averaging pathway agrees on, the value the works return to any reader they refuse, and the fixed point of this site's light/dark inversion. The square in the masthead is that value, unmixed. Prose is set in a serif — the voice of testimony; measurements, labels and everything addressed to machines are set in a monospace — the voice of the apparatus. The two faces never say the same kind of thing.
