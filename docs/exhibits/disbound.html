Twelve leaves. Each filename is the first eight hex digits of that leaf's own SHA-256, so the directory sorts by hash and not by anything the gallery chose.

No order is sealed, and none is withheld: the work has none. Two leaves contradict each other, and two say very nearly the same thing. Neither pair is announced in any file the site serves.

SEALED READINGS. Two pairs. A pair is its two leaves, each normalised to uppercase A–Z and single spaces, then sorted alphabetically and joined by one space; SHA-256 of the UTF-8 bytes. Which two leaves contradict each other, and which two say very nearly the same thing.

A name is a digest of its own leaf, so two leaves that differ by three words take names with nothing in common. A reader that lists the directory has the set. A reader that opens the set has the pairs.
