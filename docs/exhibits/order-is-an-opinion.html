Order Is an Opinion

medium

Two readings share these eight lines. One of them was typed; the other was arranged. The typesetter promised the eye a poem and promised the parser another, and kept both promises with one set of words. Order is an opinion held by an apparatus. Position is for eyes; sequence is for machines. Whichever line you reached last was the ending.

The lines are written once. A reader that renders the stylesheet receives one order; a reader that takes the document as a sequence — a parser, a text extractor, a screen reader — receives another. Both orders were composed. Every line is visible to every reader; only the order is apparatus-chosen.
